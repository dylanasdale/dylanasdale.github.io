Ideas we're exploring.

Early ideas, not products. None of these has launched.

  • Early build

    A voice for AI agents

    Natural-sounding speech for AI agents, delivered through an MCP server so almost any agent can use it. The goal is speech that is indistinguishable from a person. A first version of the server is being tested in-house.

    Speech + MCP · Early build

  • Idea

    Safety checks for health AI

    Test sets written by a registered nurse that check whether an AI's health answers are safe and accurate before patients see them.

    Health AI evaluation · Idea

  • Idea

    Agent cost meter

    Shows what each AI agent task cost, and whether a cheaper model would have done the job just as well.

    AI cost tools · Idea

  • Idea

    Private health-records assistant

    An assistant that runs on the patient's own device, so their health records never leave it.

    On-device AI · Idea

Long-term research.

A direction, not a product.

Over the long term, Asdale Dynamics is interested in AI-brain interfaces for treatment-resistant depression. This is a research direction the company is working toward. It is not a product, and nothing here is available today.
