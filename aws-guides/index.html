Every AWS Service on the Free Plan

All the services a new AWS Free plan account can use, what each one does in plain English, and any Free plan limits, sorted by category.

Compute10

Run code, from full virtual servers to functions that only exist while a request is running.

  • Amazon EC2

    Virtual servers in the cloud. Pick the CPU, memory, operating system and storage, then start and stop machines on demand.

    Free plan limit: Capacity Block purchases aren't available.

  • AWS Lambda

    Runs your code in response to events, like an HTTP request or a file upload, without any servers to manage. You pay per request and per millisecond.

    Free plan limit: Lambda@Edge isn't available.

  • Amazon Lightsail

    The simplest way to launch a server, website or database, with bundled storage and networking at a fixed monthly price.

  • AWS Elastic Beanstalk

    Upload your web app and it handles the servers, load balancing, scaling and health monitoring for you.

  • AWS Batch

    Queues and runs large numbers of batch jobs, picking the right amount of compute and scaling it up and down.

  • EC2 Image Builder

    Automates building, testing and patching the machine images and container images your servers start from.

  • Application Auto Scaling

    Adds or removes capacity for services like ECS, DynamoDB and Aurora automatically as demand changes.

  • Elastic Load Balancing

    Spreads incoming traffic across servers, containers or functions, and stops sending it to anything unhealthy.

  • AWS Serverless Application Repository

    A catalog of ready-made serverless apps you can deploy to your account in a few clicks.

  • AWS Launch Wizard

    Guided setup for complex software such as Microsoft SQL Server and SAP, sizing and deploying the AWS resources for you.

Containers6

Package apps into containers and run them on managed clusters.

  • Amazon Elastic Container Service (ECS)

    AWS's own container orchestrator. Run Docker containers on EC2 or on serverless Fargate capacity.

  • Amazon Elastic Kubernetes Service (EKS)

    Managed Kubernetes. AWS runs the control plane so you only manage your workloads.

  • Amazon EKS Anywhere

    Run the same EKS-style Kubernetes on your own hardware, in your data center or on VMware.

  • Amazon Elastic Container Registry (ECR)

    Private registry for storing, scanning and sharing your container images.

  • Amazon ECR Public

    Public registry for publishing container images that anyone can pull.

  • AWS App2Container

    Command-line tool that packages existing Java and .NET apps into containers, ready for ECS or EKS.

Storage and Backup6

Keep files, disks and backups safe and available.

  • Amazon S3

    Object storage for any amount of data: files, images, backups, static websites and data lakes.

    Free plan limit: S3 Access Grants isn't available.

  • Amazon Elastic Block Store (EBS)

    Hard drives for EC2 servers. Block storage volumes with snapshots you can copy and restore.

  • Amazon Elastic File System (EFS)

    A shared file system that many servers and containers can mount at once, and that grows and shrinks automatically.

  • AWS Backup

    One place to schedule, manage and audit backups across EC2, EBS, RDS, DynamoDB, EFS, S3 and more.

  • AWS DataSync

    Moves large amounts of data between on-premises storage, other clouds and AWS storage, fast and on a schedule.

  • AWS Backint Agent

    SAP-certified agent that backs up SAP HANA databases on EC2 straight to Amazon S3.

Databases7

Managed relational, NoSQL, in-memory and time-series databases.

  • Amazon RDS

    Managed relational databases: MySQL, PostgreSQL, MariaDB, SQL Server and Oracle. AWS handles patching, backups and failover.

  • Amazon Aurora

    AWS's high-performance MySQL- and PostgreSQL-compatible database, with a serverless option that scales automatically.

  • Amazon Aurora DSQL

    Serverless, distributed PostgreSQL-compatible database built for always-on apps, with no servers to size.

  • Amazon DynamoDB

    Serverless NoSQL key-value and document database with single-digit-millisecond responses at any scale.

  • Amazon ElastiCache

    Managed in-memory caching with Valkey, Redis OSS or Memcached, to make apps and databases faster.

  • Amazon Timestream

    Time-series database for metrics, IoT readings and other data that arrives as a stream of timestamped values.

  • AWS SQL Workbench

    Browser-based SQL editor with notebooks, charts and AI-assisted query writing, for exploring data in AWS databases such as Amazon Redshift.

Analytics and Data11

Query, move, clean, govern and visualize data.

  • Amazon Athena

    Run SQL directly on files stored in S3. No servers or loading step, and you pay per query.

  • AWS Glue

    Serverless data integration: discover, catalog, clean and transform data with ETL jobs.

  • AWS Lake Formation

    Builds and secures a data lake on S3, with fine-grained permissions down to rows and columns.

  • Amazon DataZone

    A data catalog and portal for finding, sharing and governing data across teams.

  • Amazon OpenSearch Service

    Managed OpenSearch for full-text search, log analytics and vector search.

  • Amazon OpenSearch Serverless

    OpenSearch without clusters to manage. Capacity scales automatically with your search and analytics workload.

  • Amazon Managed Workflows for Apache Airflow

    Managed Apache Airflow for scheduling and running data pipelines.

  • AWS Data Pipeline

    An older service for moving and processing data between AWS compute and storage on a schedule.

  • AWS Entity Resolution

    Matches and links records about the same customer, product or business across different datasets.

  • Amazon AppFlow

    No-code data transfers between SaaS apps such as Salesforce, Slack and Zendesk and AWS services like S3.

  • Amazon Quick

    AI-powered workspace that combines business intelligence dashboards (Quick Sight), research and chat agents over your company's data.

    Free plan limit: Only the Quick Free and Quick Plus editions are available.

AI and Machine Learning10

Foundation models, agents, and ready-made AI for images, speech and language.

  • Amazon Bedrock

    API access to foundation models from Anthropic, Amazon, Meta, Mistral and others, plus tools for knowledge bases, guardrails and agents.

  • Amazon Bedrock AgentCore

    Infrastructure to deploy and run AI agents securely at scale: runtime, memory, identity, tool gateway and observability, with any framework or model.

  • Amazon SageMaker

    AWS's unified platform for data, analytics and AI, bringing data processing, SQL analytics and model development together.

  • Amazon SageMaker AI

    Build, train, tune and deploy machine learning models with managed notebooks, training jobs and hosted endpoints.

  • Amazon SageMaker Unified Studio

    One development environment for working with data, analytics and AI models across SageMaker and Bedrock.

  • Amazon Augmented AI (A2I)

    Adds human review to machine learning predictions, sending low-confidence results to people to check.

  • Amazon Rekognition

    Image and video analysis: detect objects, text, faces and unsafe content with an API call.

  • Amazon Polly

    Turns text into lifelike speech in dozens of languages and voices.

  • Amazon Lex

    Builds chatbots and voice bots that understand natural language, using the same technology as Alexa.

  • Amazon CodeGuru Profiler

    Profiles running Java and Python apps to find the most expensive lines of code and suggest fixes.

Networking and Content Delivery9

Private networks, DNS, and getting content to users quickly.

  • Amazon VPC

    Your own private, isolated network in AWS, with subnets, route tables, gateways and firewalls.

  • Amazon CloudFront

    Global content delivery network that caches your site, APIs and video close to users.

    Free plan limit: Lambda@Edge isn't available.

  • Amazon Route 53

    DNS and domain registration, with health checks and traffic routing.

  • Amazon Route 53 Application Recovery Controller (ARC)

    Readiness checks and routing controls for shifting traffic away from an impaired location during recovery.

  • Amazon API Gateway

    Create, publish and secure REST, HTTP and WebSocket APIs in front of Lambda functions or other back ends.

  • AWS PrivateLink

    Private connections from your VPC to AWS services and other VPCs, without traffic crossing the public internet.

  • AWS Cloud Map

    Service discovery: register your app's resources by name so other services can always find them.

  • AWS Network Manager

    A central view for monitoring and managing your global network across AWS and on-premises sites.

  • AWS Data Transfer

    Moving data into, out of and within AWS. It's billed per gigabyte rather than run as a service, and most inbound transfer is free.

App Integration7

Connect services together with queues, events, notifications and workflows.

  • Amazon SQS

    Fully managed message queues that let parts of your app hand work to each other reliably.

  • Amazon SNS

    Publish-subscribe messaging that fans messages out to queues, functions, email, SMS and mobile push.

  • Amazon EventBridge

    Serverless event bus that routes events between AWS services, SaaS apps and your own code, plus a scheduler.

  • AWS Step Functions

    Visual workflows that coordinate Lambda functions and AWS services, with retries and error handling built in.

  • Amazon Simple Workflow Service (SWF)

    An older service for coordinating multi-step background jobs and tracking their state.

  • Amazon MQ

    Managed Apache ActiveMQ and RabbitMQ message brokers, for apps that already use those protocols.

  • AWS B2B Data Interchange

    Automates the exchange and transformation of EDI business documents such as orders and invoices with trading partners.

Web, Mobile and Messaging7

Build front ends, sign users in, and reach them by email and chat.

  • AWS Amplify

    Build, deploy and host full-stack web and mobile apps, with Git-based CI/CD and managed back ends.

  • AWS AppSync

    Managed GraphQL and real-time APIs that connect apps to data sources like DynamoDB and Lambda.

  • Amazon Cognito

    User sign-up and sign-in for your apps, with social and enterprise logins and secure tokens.

  • Amazon Cognito Sync

    An older Cognito feature that syncs user profile data across a user's devices.

  • Amazon Location Service

    Maps, places search, routing and geofencing APIs for adding location features to apps.

  • Amazon Simple Email Service (SES)

    Send and receive email at scale, for transactional and marketing messages.

  • AWS End User Messaging Social

    Send and receive WhatsApp messages with customers from your AWS applications.

Developer Tools10

Write, build, test, deploy and debug code.

  • AWS CodeBuild

    Managed build service that compiles code, runs tests and produces deployable packages.

  • AWS CodePipeline

    Continuous delivery pipelines that automate the build, test and deploy steps of every release.

  • AWS CodeDeploy

    Automates code deployments to EC2, on-premises servers, Lambda and ECS, with rollbacks.

  • AWS CodeCommit

    Private Git repositories hosted on AWS.

  • AWS CodeArtifact

    Private package repository for npm, PyPI, Maven, NuGet and other package formats.

  • AWS Cloud9

    Browser-based IDE for writing, running and debugging code.

  • AWS CloudShell

    A browser-based terminal with the AWS CLI already installed and signed in as you.

  • AWS X-Ray

    Traces requests as they travel through your app, to find slow spots and errors.

  • AWS AppConfig

    Safely roll out feature flags and app configuration changes, with validation and automatic rollback.

  • AWS SDKs and Tools

    Official software development kits, the AWS CLI and IDE toolkits for working with AWS from your own code.

Management and Governance22

Provision, monitor, audit and operate everything in your account.

  • AWS Management Console

    The web interface for using every AWS service.

  • AWS Console Mobile Application

    Check resources, alarms and billing from your phone.

  • AWS CloudFormation

    Infrastructure as code: describe your resources in a template and AWS creates, updates and deletes them together.

  • AWS Cloud Control API

    One consistent set of create, read, update, delete and list APIs for hundreds of AWS resource types.

  • Amazon CloudWatch

    Metrics, dashboards and alarms for your AWS resources and applications.

  • Amazon CloudWatch Logs

    Collect, store, search and analyze log files from your apps and AWS services.

  • Amazon Managed Service for Prometheus

    Managed, Prometheus-compatible monitoring for container and Kubernetes metrics.

  • AWS CloudTrail

    Records who did what in your account: every API call and console action, for auditing and troubleshooting.

  • AWS Config

    Tracks how your resources are configured over time and checks them against your rules.

  • AWS Systems Manager

    Operate servers at scale: patching, remote sessions, run commands, inventory and parameter storage.

  • AWS Systems Manager for SAP

    Automates operations such as backup and restore for SAP applications running on AWS.

  • AWS Health

    Personalized alerts about AWS events and scheduled maintenance that affect your resources.

  • AWS User Notifications

    A central place to see and route notifications from AWS services.

    Free plan limit: Creating your own notification configurations isn't available.

  • AWS Compute Optimizer

    Recommends better-fitting, often cheaper, sizes for EC2, Lambda, EBS and ECS based on actual usage.

  • AWS Well-Architected Tool

    Reviews your workloads against AWS best practices for security, reliability, cost and performance.

  • AWS License Manager

    Tracks and enforces software licenses (Microsoft, Oracle, SAP and others) across AWS and on-premises.

  • AWS Resource Explorer

    Search for any resource in your account by name, tag or type.

  • AWS Resource Groups

    Group resources by tag or stack so you can view and act on them together.

  • AWS Resource Access Manager (RAM)

    Share resources such as subnets and license configurations with other AWS accounts.

  • Service Quotas

    View the limits on each AWS service in your account and request increases.

  • AWS Support

    Help from AWS: documentation, forums, the Health Dashboard and support cases.

  • AWS Marketplace

    A catalog of third-party software, data and AI models you can subscribe to and run on AWS.

    Free plan limit: Only free listings and Bedrock model offers are available.

Security, Identity and Compliance11

Control who can do what, protect secrets and keys, and block attacks.

  • AWS Identity and Access Management (IAM)

    Users, roles and policies that control exactly who can access which AWS resources.

  • AWS Security Token Service (STS)

    Issues temporary, limited-privilege credentials for users and applications.

  • Amazon Verified Permissions

    Fine-grained authorization for your own apps, written as policies in the Cedar language.

  • AWS Directory Service

    Managed Microsoft Active Directory in AWS, or a connector to your existing directory.

  • AWS Key Management Service (KMS)

    Create and control the encryption keys that protect your data across AWS services.

  • AWS Secrets Manager

    Store, rotate and retrieve database passwords, API keys and other secrets.

  • AWS Certificate Manager (ACM)

    Free public SSL/TLS certificates for your AWS-hosted sites, renewed automatically.

    Free plan limit: Exportable public certificates aren't available.

  • AWS Payment Cryptography

    Managed cryptographic operations for card payment processing, such as PIN and card-verification handling.

  • AWS Signer

    Code signing, so you can make sure only trusted, unaltered code runs in Lambda and containers.

  • AWS WAF

    Web application firewall that filters malicious traffic such as SQL injection and bots before it reaches your app.

    Free plan limit: AWS Shield isn't available.

  • AWS Artifact

    On-demand access to AWS compliance reports and agreements, such as SOC and ISO reports.

    Free plan limit: HIPAA Business Associate and SEC rule addendums aren't available.

Cost Management3

See, budget and control what you spend.

  • AWS Billing and Cost Management

    Your bills, payments, credits and Free Tier usage, all in one console.

  • AWS Budgets

    Set spending or usage budgets and get alerts before you go over them.

  • AWS Cost Explorer

    Charts and reports that break down your costs and usage over time, with forecasts.

Internet of Things5

Connect, manage and secure devices, and model the physical world.

  • AWS IoT Core

    Connects devices to the cloud securely and routes their messages to other AWS services.

    Free plan limit: AWS IoT Greengrass isn't available.

  • AWS IoT Device Management

    Register, organize, monitor and remotely update fleets of IoT devices.

  • AWS IoT Device Defender

    Audits IoT device security settings and detects unusual device behavior.

  • AWS IoT SiteWise

    Collects and organizes data from industrial equipment so you can monitor and analyze it.

  • AWS IoT TwinMaker

    Builds digital twins: live 3D models of buildings, factories and equipment linked to real data.

Migration1

Move existing servers and workloads to AWS.

  • AWS Transform MGN

    Lift-and-shift migration of physical, virtual and cloud servers to AWS, with continuous replication and cutovers measured in minutes. Formerly AWS Application Migration Service.

Based on AWS's list of services included in the Free plan, checked October 18, 2026. AWS changes this list often, so check your own account before relying on it.
